# PrévenSanté CI

Site vitrine statique de PrévenSanté CI, prêt pour GitHub Pages.

## Publication

1. Créer un dépôt GitHub public nommé `prevensante-ci`.
2. Importer `index.html` et `.nojekyll` à la racine du dépôt.
3. Ouvrir **Settings > Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche **main** et le dossier **/(root)**, puis enregistrer.

Le site sera disponible à l'adresse :
`https://VOTRE-NOM-UTILISATEUR.github.io/prevensante-ci/`
