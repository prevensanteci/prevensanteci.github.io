PUBLICATION
1. Décompresser ce dossier.
2. Téléverser TOUT son contenu à la racine du dépôt prevensanteci.github.io.
3. Conserver l'arborescence assets/css, assets/js, assets/images et assets/icons.
4. Ne pas téléverser uniquement index.html.
5. Attendre le déploiement GitHub Pages puis ouvrir https://prevensanteci.github.io/

AMÉLIORATIONS DE CETTE VERSION
- Images sorties du HTML et converties en WebP.
- Images secondaires en lazy-loading.
- CSS et JavaScript séparés.
- Parcours RDV : Besoin → localisation/créneau → coordonnées/consentement → confirmation.
- Consentement horodaté avec identifiant et version de politique.
- Formulaire public limité aux données utiles au rappel.
- Aucune ordonnance, résultat ou document médical transmis par le formulaire public.
- Pages : confidentialité, données de santé, mentions légales, conditions d'utilisation.
- Hiérarchie : Hero → Services → Comment ça marche → Packs → Coordination → Médecin → Entreprises → FAQ → Urgences.
- Optimisations smartphone Android et accessibilité clavier.
- Assistant renommé Assistant PrévenSanté.

IMPORTANT
Le formulaire utilise FormSubmit comme relais de messagerie pour les données minimales de rappel.
Les documents médicaux doivent être transmis seulement par un canal approprié après contact avec l'équipe.
